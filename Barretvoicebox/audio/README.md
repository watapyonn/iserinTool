# 音声ファイル格納フォルダ (`audio/`)

各セリフに対応する音声ファイル（`.mp3`, `.wav`, `.ogg` など）をこのフォルダ内に格納してください。

## 使い方

1. お手持ちの音声ファイル（例: `voice_001.mp3`, `voice_002.mp3`）を本フォルダ (`audio/`) に配置します。
2. `js/voices.js` ファイルを開き、対象セリフの `audio` プロパティにパスを指定します。

```javascript
// 例: js/voices.js
{ id: 1, text: "星の命が削られてるんだぞ！", label: "星の命が削られてる！", audio: "audio/voice_001.mp3" },
{ id: 2, text: "アバランチの時間だぜ！", label: "アバランチの時間だぜ！", audio: "audio/my_custom_voice.mp3" },
```

## 音声ファイルが指定されていない・読み込めない場合

- `audio` の値が空文字（`""`）の場合や、指定したファイルが存在しない（404エラー等）場合は、自動的に**ブラウザの合成音声（SpeechSynthesis）**で読み上げられます。
