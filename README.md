# ISERI TOOL HUB 🎮

ファイナルファンタジーシリーズ（FF7 / FF14）の各種ファンメイド・ユーティリティツールを統合したポータルWebアプリケーションです。

---

## 🚀 収録ツール

### 1. 🔫 バレット ボイスBOX アルティメット (FFVII)
- **概要**: バレット・ウォーレスの熱いシャウトや名言など100種類のボイスを再生できるサウンドツール。
- **特徴**: クラシックFF7ウィンドウUI、アイコン3形態切り替え、ブラウザ音声合成再生。
- **パス**: `Barretvoicebox/barret_voice_box_ultimate.html`

### 2. 🌸 タタル・タル なりきり変換ツールでっす！ (FFXIV)
- **概要**: 入力した文章を「暁の血盟」受付嬢タタル・タルの口調にリアルタイム変換するツール。
- **特徴**: リアルタイム変換、ワンクリッククリップボードコピー、可愛い吹き出しプレビュー。
- **パス**: `tatarutool/code_artifact (1).html`
